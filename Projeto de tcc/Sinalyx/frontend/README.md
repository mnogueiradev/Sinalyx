# Sinalyx Frontend

Base Vue 3 + Vite + TypeScript + Tailwind CSS para o painel do Sinalyx.

## Configuracao

```bash
cp .env.example .env
```

Edite `VITE_API_BASE_URL` se a API FastAPI nao estiver em `http://localhost:8000`.

## Execucao

```bash
npm install
npm run dev
```

Build de producao:

```bash
npm run build
```
